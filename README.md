## Beginner courses<a id='beginnerCourses'></a>
* [UX Foundations: Accessibility](https://www.linkedin.com/learning/ux-foundations-accessibility) by Derek Featherstone, LinkedIn Learning. Good intro to accessibility, users and the barriers people face.
* [Web Accessibility Tutorials](https://www.w3.org/WAI/tutorials/) by W3C WAI. Helpful examples and detail to build on the foundations course.
* [Accessibility for Web Design](https://www.linkedin.com/learning/accessibility-for-web-design) by Derek Featherstone, LinkedIn Learning. Granular examples and how-tos. A solid extension of the foundations course.
* [A11ycasts with Rob Dodson](https://www.youtube.com/playlist?list=PLNYkxOF6rcICWx0C9LVWWVqvHlYJyqw7g) on YouTube. Granular examples with a code and screen reader focus.

## Cognitive disabilities<a id='cognitive'></a>
* [Accessible Numbers](https://accessiblenumbers.com/): guidelines for presenting numbers and data clearly, covering low numeracy and dyscalculia.
* [An Introductory Guide to Understanding Cognitive Disabilities](https://www.deque.com/blog/an-introductory-guide-to-understanding-cognitive-disabilities/) by Deque.

## Web Resources<a id='webResources'></a>
* [MDN HTML Docs](https://developer.mozilla.org/en-US/docs/Web/HTML): the authoritative reference for HTML specs.
* [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) by W3C. ARIA specs and worked examples.
* [WAI-ARIA 1.1 Cheat Sheet](https://cheatography.com/jreiche/cheat-sheets/wai-aria-1-1/): roles, attributes, global states, properties and landmarks at a glance.
* [Accessibility Support](https://a11ysupport.io/): community-driven tests showing how component builds behave with screen readers.
